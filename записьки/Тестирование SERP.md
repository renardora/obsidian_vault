### **Проверка основного функционала РПУ**

1. [ ] **Управление проектами (CRUD)** – Проверка создания, редактирования, фильтрации проекта и расчета его статуса на основе этапов.
2. [ ] **Виджеты на карточке проекта** – Проверка, что виджеты "Сальдо/Рентабельность", "Общая стоимость", "Документы", "Трудозатраты" отображают корректные рассчитанные данные.
3. [ ] **Договоры и ДС** – Проверка создания иерархии Договор -> ДС, валидации дат и расчета финансовых показателей (Бюджет, Факт. затраты, Сальдо, Рентабельность).
4. [ ] **Исполнение (Ключевая проверка)** – Проверка создания этапа, алгоритма автопривязки треков из ЛК, отображения детализации по сотрудникам и **расчета фактических затрат** с использованием ставок сотрудников.
5. [ ] **Ставки сотрудников** – Проверка установки зарплаты, автоматического расчета ставки руб/час, ограничений на редактирование и корректного использования ставки в расчетах раздела "Исполнение".
6. [ ] **График занятости (Просмотр)** – Проверка автовыбора периода, отображения часов и отсутствий, расчета нормы и разницы с учетом производственного календаря.

### **Проверка остального функционала**

1. [ ] **ЛК: Ручные типы задач** – Проверка создания, редактирования, удаления и дублирования задач типов "Аутстафф", "Управление", "Самообучение" (без валидации).
2. [ ] **ЛК: Фильтры и Тепловая карта** – Проверка фильтрации табеля по периоду, проектам, статусу и работы тепловой карты активности.
3. [ ] **РПУ: График занятости (Управление отсутствиями)** – Проверка массового проставления отсутствий, редактирования через двойной клик и отображения конфликта часов и отсутствия.
4. [ ] **РПУ: График занятости (Детализация по проектам)** – Проверка развертывания строки сотрудника для просмотра распределения его часов по проектам и расчета коэффициента загрузки.
5. [ ] **РПУ: График занятости (Неделя vs Месяц)** – Проверка переключения между недельным и месячным представлением табеля и корректности расчетов для недели.
6. [ ] **Ролевая модель** – Проверка корректности разграничения прав доступа: сотрудник не видит РПУ, ПМ не редактирует ставки, финменеджер имеет полный доступ.
