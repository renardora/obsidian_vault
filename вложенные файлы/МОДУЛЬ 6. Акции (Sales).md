Включает:  
- Экран «Акции» (список промо)  
- Отображение условий и сроков акций  
- Доступность акций для авторизованных / неавторизованных  
- Открытие детальной карточки акции / условий  

---

## 1. Краткий обзор модуля

- Назначение:  
  Раздел «Акции» отображает актуальные специальные предложения и скидки, действующие в фирменных магазинах «Дороничи». Пользователь может просматривать текущие акции, их условия и сроки действия. 

- Основные сценарии:  
  - Авторизованный пользователь видит список доступных акций и может открыть условия каждой. 
  - Неавторизованный пользователь видит заглушку с предложением авторизоваться, т.к. дополнительные скидки доступны только участникам программы. 

---

## 2. Группы проверок

- Базовое отображение списка акций  
- Доступность для авторизованных / неавторизованных  
- Детальная карточка / условия акции  
- Состояние «нет активных акций»  
- Ошибки сети / CMS  

---

## 3. Тест-кейсы (префикс `SALES-XXX`)

### 3.1. Базовое отображение списка акций

- `SALES-001: Отображение списка акций для авторизованного пользователя`
  - Шаги:
    1. Авторизоваться в приложении.  
    2. Открыть раздел «Акции» из меню или с главного экрана.  
  - ОР:
    - Отображается список акций (например: «Акция недели», «Акция месяца»). 
    - По каждой акции видны: название, краткое описание/условия, даты действия.

- `SALES-002: Корректность базовой карточки акции в списке`
  - Шаги:
    1. Открыть «Акции» (авторизованный).  
    2. Просмотреть одну карточку акции в списке.  
  - ОР:
    - Отображаются ключевые атрибуты:  
      - Название/тип акции (например, «-20% на колбасы»).  
      - Краткое условие (что нужно сделать, чтобы получить выгоду).  
      - Срок действия (дата начала и окончания).  
    - Карточка кликабельна (ведет к деталям акции).  

---

### 3.2. Доступность для авторизованных / неавторизованных

- `SALES-010: Акции для неавторизованного пользователя`
  - Шаги:
    1. Выйти из аккаунта / запустить приложение как гость.  
    2. Открыть раздел «Акции».  
  - ОР:
    - Вместо списка акций отображается сообщение:  
      «Только участники программы лояльности получают дополнительные скидки…» + кнопка «Авторизоваться». 
    - Список акций не доступен до авторизации.  

- `SALES-011: Переход к авторизации из заглушки акций`
  - Шаги:
    1. В состоянии неавторизованного открыть «Акции».  
    2. Нажать кнопку «Авторизоваться».  
  - ОР:
    - Открывается экран входа/регистрации.  
    - После успешного входа при повторном заходе в «Акции» отображается список акций.  

---

### 3.3. Детальная карточка / условия акции

- `SALES-020: Просмотр условий акции`
  - Шаги:
    1. Открыть «Акции» (авторизованный).  
    2. Нажать на любую акцию в списке.  
  - ОР:
    - Открывается модальное окно «Условия акции». 
    - Виден полный текст условий: кто участвует, на какие товары, как получить скидку/бонусы, ограничения.  
    - Отображаются даты действия и, при необходимости, магазины-участники. 
    - Есть кнопка «Закрыть», которая возвращает к списку акций.  

- `SALES-021: Корректная длина и формат условий`
  - Шаги:
    1. Открыть детальную карточку акции с длинным текстом условий.  
  - ОР:
    - Текст прокручивается, не обрезается.  
    - Ссылки/важные части (например, «подробные правила на сайте») оформлены кликабельно, если предусмотрено.

---

### 3.5. Состояние «нет активных акций»

- `SALES-040: Пустое состояние раздела акций`
  - Шаги:
    1. Убедиться, что в CMS нет ни одной активной акции (или использовать тестовую среду).  
    2. Открыть «Акции» (авторизованный пользователь).  
  - ОР:
    - Отображается заглушка вида:  «Сейчас нет активных акций». 
    - Нет пустого белого экрана.  
    - Основная навигация (меню, переходы назад) работает.  

---

### 3.6. Ошибки сети / CMS

- `SALES-050: Нет интернета при открытии раздела акций`
  - Шаги:
    1. Отключить интернет.  
    2. Открыть «Акции» (авторизованный).  
  - ОР:
    - Отображается сообщение о проблеме с подключением («Нет интернета»).  
    - Список акций не отображается / не обновляется.  
    - Есть возможность повторить попытку (кнопка «Обновить» / «Повторить»). 

- `SALES-051: Ошибка сервера CMS/Mindbox при загрузке акций`
  - Шаги:
    1. Сымитировать ошибку 5xx от CMS/сервера, отдающего список акций.  
    2. Открыть раздел «Акции».  
  - ОР:
    - Отображается понятное пользователю сообщение об ошибке («Не удалось загрузить акции»).  
    - Остальной интерфейс приложения остаётся работоспособным (можно уйти в другие разделы).  

- `SALES-052: Долгая загрузка акций (таймаут)`
  - Шаги:
    1. Сымитировать очень медленный ответ сервера акций.  
    2. Открыть раздел «Акции».  
  - ОР:
    - Отображается индикатор загрузки/скелетон, а не пустой экран.  
    - При истечении таймаута пользователь видит сообщение об ошибке и возможность повторить запрос. 

---

### 3.7. Навигация и возвраты

- `SALES-060: Возврат из условий акции к списку`
  - Шаги:
    1. Открыть любую акцию → перейти в «Условия акции».  
    2. Нажать «Закрыть».  
  - ОР:
    - Пользователь возвращается к тому же списку акций.  
    - Скролл-позиция списка сохранена (возврат к той же акции).
