Включает:  
- Экран «Чат» (нижнее меню)  
- Открытие чата из других мест (профиль / модалки)  
- Обмен сообщениями с оператором  
- (Опционально) отправка изображений  
- Сохранение истории переписки  

---

## 1. Краткий обзор модуля

**Назначение:**  
Раздел «Чат» предназначен для оперативной коммуникации пользователя со службой поддержки. Реализуется на базе JivoChat или аналогичного сервиса, с обменом текстовыми сообщениями, возможностью прикрепления изображений (если поддерживается) и сохранением истории переписки. 

**Ключевые сценарии:**  
- Открытие чата из нижнего меню.
- Открытие чата из модалки при попытке изменить дату рождения в профиле. 
- Отправка/получение сообщений. 
- Сохранение истории диалога. 

---

## 2. Группы проверок

- Базовое открытие чата  
- Отправка и приём сообщений  
- Открытие чата из других модулей (профиль / модалки)  
- История переписки  
- Вложения (изображения) — если включено в интеграции 
- Ошибки сети / недоступность сервиса  
- Состояния авторизован / неавторизован 

---

## 3. Тест-кейсы (префикс `CHAT-XXX`)

### 3.1. Базовое открытие чата

- `CHAT-001: Открытие чата из нижнего меню`
  - Шаги:
    1. Авторизоваться (или быть гостем — по факту реализации).  
    2. Нажать «Чат» в нижнем меню.  
  - ОР:
    - Открывается экран чата поддержки.  
    - Вверху отображается должность и фотография оператора. 

- `CHAT-002: Возврат из чата назад`
  - Шаги:
    1. Открыть чат.  
    2. Нажать кнопку «Назад» / жест системного back.  
  - ОР:
    - Возврат на предыдущий экран.  

---

### 3.2. Отправка и приём сообщений

- `CHAT-010: Отправка текстового сообщения`
  - Шаги:
    1. Открыть чат.  
    2. Ввести текст в поле ввода.  
    3. Нажать кнопку отправки.  
  - ОР:
    - Сообщение появляется в ленте сообщений как отправленное от пользователя. 

- `CHAT-011: Приём ответа от оператора`
  - Шаги:
    1. Открыть чат.  
    2. Отправить любое сообщение.  
    3. Дождаться ответа оператора (в тестовой среде можно сымитировать).  
  - ОР:
    - Ответ отображается в ленте с пометкой оператора (другой цвет/выравнивание).  
    - Вверху сообщения отображено имя оператора.
    - Порядок сообщений корректный.  

- `CHAT-012: Отправка пустого сообщения`
  - Шаги:
    1. Открыть чат.  
    2. Оставить поле ввода пустым.  
    3. Попробовать нажать «Отправить».  
  - ОР:
    - Кнопка отправки неактивна. 

- `CHAT-013: Отправка длинного сообщения`
  - Шаги:
    1. Ввести очень длинный текст (несколько абзацев).  
    2. Нажать «Отправить».  
  - ОР:
    - Сообщение отправлено и корректно отображается (многострочный bubble, скролл по истории).  

---

### 3.3. Открытие чата из других модулей

- `CHAT-020: Переход в чат из модалки при попытке изменить дату рождения`
  - Шаги:
    1. В Профиле попытаться изменить дату рождения.  
    2. В модальном окне нажать «Перейти в чат». 
  - ОР:
    - Открывается чат поддержки.  
    - Пользователь видит форму ввода сообщения.  
    - ==Контекст запроса (например, «изменить дату рождения») может быть подставлен автоматически в первое сообщение/описание, если предусмотрено.== 

- `CHAT-021: Возврат в профиль после чата`
  - Шаги:
    1. Перейти в чат из модалки профиля.  
    2. Завершить диалог (или просто нажать «Назад»).  
  - ОР:
    - Возврат к профилю или предыдущему экрану.  

---

### 3.4. История переписки

- `CHAT-030: Сохранение истории чата при повторном открытии`
  - Шаги:
    1. Открыть чат, отправить несколько сообщений.  
    2. Закрыть чат (перейти в другой раздел).  
    3. Снова открыть чат через нижнее меню.  
  - ОР:
    - Вся предыдущая переписка отображается (история не очищена).

- `CHAT-031: Сохранение истории между сессиями приложения`
  - Шаги:
    1. Открыть чат, написать сообщение.  
    2. Закрыть приложение полностью.  
    3. Снова открыть приложение, перейти в «Чат».  
  - ОР:
    - История переписки отображается.  

---

### 3.5. Вложения (изображения) — если поддерживаются

- `CHAT-040: Отправка изображения из галереи` 
  - Шаги:
    1. Открыть чат.  
    2. Нажать иконку вложения (скрепка/камера).  
    3. Выбрать изображение из галереи.  
  - ОР:
    - Изображение прикреплено и отображается в переписке.  
    - При нажатии открывается в полноэкранном просмотре.  

- `CHAT-041: Ошибка при отправке изображения (обрыв сети)` 
  - Шаги:
    1. Начать отправку изображения.  
    2. Во время загрузки отключить интернет.  
  - ОР:
    - Пользователь видит сообщение об ошибке отправки.  
    - Есть возможность повторно отправить изображение.  

---

### 3.6. Ошибки сети / недоступность сервиса

- `CHAT-050: Нет интернета при открытии чата`
  - Шаги:
    1. Отключить интернет.  
    2. Нажать «Чат» в нижнем меню.  
  - ОР:
    - Появляется заглушка «Нет соединения».  

- `CHAT-051: Нет интернета при отправке сообщения`
  - Шаги:
    1. Открыть чат при наличии сети.  
    2. Ввести текст, затем отключить интернет.  
    3. Нажать «Отправить».  
  - ОР:
    - Появляется ошибка «Сообщение не отправлено».  
    - Сообщение остаётся в ленте с пометкой об ошибке и возможностью «повторить». 

- `CHAT-052: Недоступность сервиса JivoChat / сервера чата`
  - Шаги:
    1. Сымитировать отказ сервиса чата (ошибка 5xx / недоступен SDK).  
    2. Попробовать открыть чат.  
  - ОР:
    - Отображается сообщение «Сервис поддержки временно недоступен».  
    - Пользователь может вернуться назад.  

---

### 3.7. Состояния авторизован / неавторизован

- `CHAT-060: Использование чата авторизованным пользователем`
  - Шаги:
    1. Авторизоваться.  
    2. Открыть чат.  
    3. Отправить сообщение с вопросом по бонусам / заказу.  
  - ОР:
    - Оператор получает запрос с привязкой к профилю пользователя (телефон, имя) — на стороне оператора.
    - Для пользователя — обычный сценарий чата (сообщение отправлено, можно продолжать переписку).  

- ==`CHAT-061: Использование чата неавторизованным пользователем`==
  - Шаги:
    1. Выйти из аккаунта.  
    2. Открыть чат.  
  - ОР:
    - Либо чат доступен как «гостевой» (без привязки к аккаунту),  
      либо показывается заглушка «Авторизуйтесь, чтобы писать в поддержку».  

---

### 3.8. UX и стабильность

- `CHAT-070: Корректное поведение клавиатуры`
  - Шаги:
    1. Открыть чат.  
    2. Нажать в поле ввода (клавиатура открывается).  
    3. Пролистать историю сообщений.  
  - ОР:
    - История прокручивается, поле ввода остаётся доступным.  
    - Клавиатура не перекрывает последние сообщения.  

- `CHAT-071: Плавность работы чата при длинной истории`
  - Шаги:
    1. Сымитировать чат с большим количеством сообщений.  
    2. Прокрутить историю вверх-вниз.  
  - ОР:
    - Нет фризов, лагов, падений приложения.
