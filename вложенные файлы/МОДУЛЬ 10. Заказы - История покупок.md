# МОДУЛЬ 10. Заказы / История покупок  
Включает:  
- Экран «Мои заказы» (история покупок)  
- Отображение списка заказов  
- Детальная карточка заказа  
- Информация о начисленных/списанных бонусах  
- Информация о магазине, дате, составе заказа  
- Ошибки загрузки, пустое состояние, навигация  

---

## 1. Краткий обзор модуля

**Назначение:**  
Раздел «Заказы» позволяет пользователю просматривать историю покупок, детали каждого заказа: состав, сумму, начисленные и списанные бонусы, информацию о магазине, времени покупки, а также использовать эти данные для сверки. 

Основное содержимое:  
- Список заказов: дата, номер/ID заказа, сумма, магазин.  
- Карточка заказа: товары, количества, цены, начисленные/списанные бонусы, итоговая сумма, магазин, дата/время.  
- Состояние «заказов нет».  
- Ошибки сети / сервера.  

---

## 2. Группы проверок

- Отображение списка заказов  
- Пустое состояние (нет заказов)  
- Детальная карточка заказа  
- Ошибки сети / сервера  
- Навигация в/из деталей заказа  
- Производительность / корректность загрузки  

---

## 3. Тест-кейсы (префикс `ORD-XXX`)

---

### 3.1. Список заказов

- `ORD-001: Отображение списка заказов`
  - Шаги:
    1. Авторизоваться пользователем, у которого есть заказы.  
    2. Открыть «История покупок».  
  - ОР:
    - Отображается список заказов: дата, номер/ID заказа, сумма, баллы (списанные/начисленные), магазин.  
    - Список прокручиваемый, без дубликатов.

- `ORD-002: Заказы отсортированы по дате`
  - Шаги:
    1. Открыть список заказов.  
  - ОР:
    - Заказы отсортированы по убыванию даты (сначала новые). 

- ==`ORD-003: Заказы с разным статусом`==
  - Шаги:
    1. Загрузить пользователя с заказами разных типов (продажа, возврат). 
  - ОР:
    - Статусы отображаются корректно, если предусмотрено (например, возврат).  

---

### 3.2. Пустое состояние

- `ORD-010: Нет заказов у пользователя`
  - Шаги:
    1. Авторизоваться новым пользователем без заказов.  
    2. Открыть «История покупок».  
  - ОР:
    - Отображается заглушка: «У вас пока нет покупок».  
    - Нет пустого белого экрана.  

---

### 3.3. Детальная карточка заказа

- `ORD-020: Открытие деталей заказа`
  - Шаги:
    1. Открыть «История покупок».  
    2. Нажать на любой заказ.  
  - ОР:
    - Открывается карточка заказа.  
    - Видны: номер, дата, магазин, товары, количества, цены, начисленные баллы, итоговая сумма.
    - Дата и время отображены корректно.  
    - Товары отображены списком: название, цена, количество, итог по позиции. 
    - Отображается итоговая сумма по чеку (с учётом скидок/бонусов).  
    - Нет перескока/некорректных данных.

- `ORD-022: Отображение начисленных бонусов`
  - Шаги:
    1. Открыть заказ, где есть начисление бонусов.  
  - ОР:
    - Отображена строка «Начислено бонусов: X».  
    - Значение совпадает с изменением общего баланса. 

- `ORD-023: Отображение списанных бонусов`
  - Шаги:
    1. Открыть заказ со списанием бонусов.  
  - ОР:
    - Отображено «Списано бонусов: X».  
    - Значение соответствует данным в заказе.
    - Значение совпадает с изменением общего баланса. 


---

### 3.5. Ошибки сети / сервера

- `ORD-040: Нет интернета при открытии списка заказов`
  - Шаги:
    1. Отключить интернет.  
    2. Открыть «История покупок».  
  - ОР:
    - Отображается заглушка «Нет соединения».  
    - Есть кнопка «Повторить попытку».  

- `ORD-041: Ошибка сервера при загрузке заказов`
  - Шаги:
    1. Сымитировать ответ 5xx от сервиса заказов.  
    2. Открыть «История покупок».  
  - ОР:
    - Показано сообщение «Ошибка загрузки заказов».  
    - Основной UI приложения не ломается.  

- `ORD-042: Ошибка загрузки деталей заказа`
  - Шаги:
    1. Сымитировать недоступность / ошибку API конкретного заказа.  
    2. Нажать на заказ.  
  - ОР:
    - Появляется сообщение об ошибке.  
    - Пользователь может вернуться в список.  

---

### 3.6. Навигация

- `ORD-050: Возврат из деталей заказа к списку`
  - Шаги:
    1. Открыть заказ.  
    2. Нажать «Назад».  
  - ОР:
    - Пользователь возвращается в список на ту же позицию.  

- `ORD-062: Переход в карточку товара`
  - Шаги:
    1. В деталях заказа нажать на карточку товара.  
  - ОР:
    - Открывается карточка выбранного товара.  
    - Возврат → возвращает в заказ.

---

### 3.7. Производительность

- `ORD-060: Быстрая загрузка истории заказов`
  - Шаги:
    1. Открыть «История покупок» с нормальным интернетом.  
  - ОР:
    - История загружается быстро (<1 сек на целевых устройствах). 

- `ORD-061: Плавная прокрутка большого списка заказов`
  - Шаги:
    1. Авторизоваться тестовым пользователем с большим количеством заказов (>50).  
    2. Прокрутить список.  
  - ОР:
    - Нет рывков, подфризов, дублирования записей.
