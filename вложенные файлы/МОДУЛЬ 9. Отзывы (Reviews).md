Включает:  
- Просмотр отзывов  
- Создание отзыва  
- Статусы отзыва (новый → модерация → опубликован / отклонён) 
- Переходы из карточки товара в отзывы  
- Состояния «нет отзывов», ошибки сети  

---

## 1. Краткий обзор модуля

**Назначение:**  
Раздел «Отзывы» позволяет пользователям читать мнения о товарах и оставлять собственные отзывы.  
Отзывы привязаны к конкретному товару, доступны из карточки товара и через прямую навигацию (если предусмотрено).

**Основной функционал:**  
- Просмотр списка отзывов  
- Фильтрация/сортировка по рейтингу (если предусмотрено)
- Создание нового отзыва  
- Переход к отзывам из карточки товара  
- Пустое состояние при отсутствии отзывов  
- Обработка ошибок сети/сервера  

---

## 2. Группы проверок

- Просмотр отзывов  
- Состояние «нет отзывов»  
- Создание отзыва  
- Валидация формы отзыва  
- Статусы отправленного отзыва  
- Ошибки сети / сервера  
- Навигация в/из карточки товара  

---

## 3. Тест-кейсы (префикс `REV-XXX`)

---

### 3.1. Просмотр отзывов

- `REV-001: Отображение списка отзывов`
  - Шаги:
    1. Открыть карточку товара.  
    2. Нажать «Отзывы».  
  - ОР:
    - Отображается список отзывов: имя автора/оценка/дата/текст (если есть).  
    - Список прокручиваемый, без дубликатов.

- `REV-002: Корректное открытие отзыва из карточки товара`
  - Шаги:
    1. Перейти к отзывам из карточки.  
  - ОР:
    - Загружены отзывы именно для выбранного товара.  
    - Нет смешения отзывов разных товаров.

- `REV-003: Пагинация / подгрузка отзывов при прокрутке` (если предусмотрено)
  - Шаги:
    1. Пролистать список отзывов до конца.  
  - ОР:
    - Подгружаются следующие отзывы.  
    - Нет скачков/скачивания обратно.  

---

### 3.2. Состояние «нет отзывов»

- `REV-010: Отсутствие отзывов`
  - Шаги:
    1. Открыть отзывы для товара, у которого они отсутствуют.  
  - ОР:
    - Отображается заглушка «Пока нет отзывов».  
    - Нет пустого белого экрана.

- `REV-011: Переход к форме отзыва при отсутствии отзывов`
  - Шаги:
    1. На экране пустых отзывов нажать «Оставить отзыв».  
  - ОР:
    - Открывается форма создания нового отзыва.

---

### 3.3. Создание отзыва

- `REV-020: Успешное создание нового отзыва`
  - Шаги:
    1. Открыть форму создания отзыва.  
    2. Заполнить поля: текст, рейтинг.  
    3. Нажать «Отправить».  
  - ОР:
    - Появляется сообщение «Отзыв отправлен на модерацию» / «Спасибо за отзыв».  
    - Отзыв не появляется сразу в списке (включена модерация). 

- `REV-021: Создание отзыва без рейтинга` 
  - Шаги:
    1. Заполнить форму отзыва без оценки.  
  - ОР:
    - Появляется ошибка «Укажите оценку».  

- `REV-022: Создание отзыва с минимальным количеством текста`
  - Шаги:
    1. Ввести короткий текст (например, 3–5 символов).  
    2. Отправить.  
  - ОР:
    - Если валидация есть → ошибка «Слишком короткий отзыв».  
    - Если нет → отзыв отправлен.  

---

### 3.4. Валидации

- `REV-030: Отправка пустого отзыва`
  - Шаги:
    1. Открыть форму создания отзыва.  
    2. Не заполнять текст.  
    3. Нажать «Отправить».  
  - ОР:
    - Ошибка: «Введите текст отзыва».  
    - Кнопка отправки остаётся неактивна или сохраняет состояние ошибки.  

- `REV-031: Ограничение длины текста отзыва`
  - Шаги:
    1. Ввести очень длинный текст (например, >1000 символов).  
  - ОР:
    - Либо текст обрезается, либо показывается ошибка.  

---

### 3.5. Статусы отзыва (модерация)

- `REV-040: Отзыв сразу после отправки (статус «На модерации»)`
  - Шаги:
    1. Отправить отзыв.  
    2. Открыть список отзывов.  
  - ОР:
    - Новый отзыв **не отображается**, либо отображается с пометкой «На модерации».  

- `REV-041: Появление отзыва после модерации`
  - Шаги:
    1. Отправить отзыв.  
    2. На тестовом сервере изменить статус → «Одобрен».  
    3. Обновить отзывы.  
  - ОР:
    - Отзыв появляется в списке.  

- `REV-042: Отклонённый отзыв`
  - Шаги:
    1. Отправить отзыв.  
    2. На сервере пометить «Отклонён».  
  - ОР:
    - Отзыв не появляется в списке.  
    - Возможно, пользователь получает уведомление (если предусмотрено). 

---

### 3.6. Ошибки сети / сервера

- `REV-050: Ошибка сети при загрузке отзывов`
  - Шаги:
    1. Отключить интернет.  
    2. Открыть экран отзывов.  
  - ОР:
    - Отображается заглушка «Нет соединения».  
    - Есть кнопка «Повторить».

- `REV-051: Ошибка сервера при загрузке отзывов`
  - Шаги:
    1. Сымитировать ошибку 5xx.  
  - ОР:
    - Сообщение «Не удалось загрузить отзывы».  
    - Интерфейс не зависает.

- `REV-052: Ошибка при отправке отзыва`
  - Шаги:
    1. Заполнить отзыв.  
    2. Сымитировать ошибку сервера при отправке.  
  - ОР:
    - Отображается сообщение «Ошибка отправки».  
    - Текст отзыва в форме остаётся, не теряется.

---

### 3.7. Навигация

- `REV-060: Возврат из отзывов в карточку товара`
  - Шаги:
    1. Открыть отзывы.  
    2. Нажать «Назад».  
  - ОР:
    - Возвращает в ту же карточку товара.  
    - Скролл-позиция в карточке сохранена.
