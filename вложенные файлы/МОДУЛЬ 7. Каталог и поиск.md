Включает:  
- Catalog (список товаров и категорий)  
- Search  
- Filters  
- Sort  
- Состояния: пустой поиск, нет товаров  

---

## 1. Краткий обзор модуля

- Каталог отображает актуальный ассортимент товаров сети «Дороничи», структура многоуровневая: категории → подкатегории → список товаров.
- Категория: картинка + название. 
- Товар в списке: картинка, цена, старая цена (опционально), название, вес, бейдж (скидка/новинка и т.п.), рейтинг (если есть).
- Поиск: по наименованию, с динамическими подсказками по мере ввода; при отсутствии результатов — заглушка «Ничего не найдено».
- Каталог должен загружаться ≤ 2 сек, есть кэширование каталога и работа при слабом интернете.

---

## 2. Группы проверок

- Базовая навигация по каталогу (категории / подкатегории / список товаров)  
- Отображение списка товаров и карточек в листинге  
- Фильтры (отбор по атрибутам) 
- Сортировка (цена, популярность и т.п.) 
- Поиск (валидные запросы, подсказки)  
- Пустой поиск / нет результатов  
- Пустые категории / «нет товаров»  
- Производительность и кэширование  
- Ошибки сети / PIM  

---

## 3. Тест-кейсы (префикс `CAT-XXX`)

### 3.1. Навигация по каталогу

- `CAT-001: Отображение корневых категорий`
  - Шаги:
    1. Открыть экран «Каталог» из главного экрана.  
  - Ожидаемый результат:
    - Отображается список категорий с названием и изображением. 
    - Нет ошибок и пустых плиток.

- `CAT-002: Переход в подкатегорию`
  - Шаги:
    1. На экране «Каталог» выбрать категорию, которая содержит подкатегории. 
  - ОР:
    - Открывается список подкатегорий.  
    - В шапке видно, в какой категории сейчас находится пользователь. 

- `CAT-003: Переход в список товаров (листинг) из категории`
  - Шаги:
    1. Выбрать категорию без подкатегорий.  
  - ОР:
    - Открывается список товаров этой категории. 

---

### 3.2. Отображение списка товаров

- `CAT-010: Атрибуты товара в списке`
  - Шаги:
    1. Открыть категорию с товарами.  
    2. Просмотреть одну карточку товара в списке.
  - ОР:
    - На карточке отображаются:  
      - изображение товара;  
      - конечная цена;  
      - цена до скидки (если есть);  
      - название товара;  
      - вес;  
      - бейдж (если задан);
      - рейтинг (если есть).

- `CAT-011: Прокрутка длинного списка товаров`
  - Шаги:
    1. Открыть категорию с большим количеством товаров.  
    2. Пролистать список до конца.
  - ОР:
    - Список прокручивается плавно.  
    - Никакие товары не дублируются/не пропадают при прокрутке.   

- `CAT-012: Переход из листинга в карточку товара`
  - Шаги:
    1. Нажать на любой товар в списке.  
  - ОР:
    - Открывается экран карточки товара, соответствующий выбранному товару. 

---

### 3.3. Фильтры (Filters)

- `CAT-020: Применение одного фильтра`
  - Шаги:
    1. Открыть категорию с товарами.  
    2. Открыть панель «Фильтры».  
    3. Выбрать один фильтр (например, бренд / тип продукта). 
    4. Применить фильтр.
  - ОР:
    - Отображаются только товары, удовлетворяющие выбранному фильтру.
    - Чип/индикатор активного фильтра виден пользователю. 

- `CAT-021: Сброс фильтров`
  - Шаги:
    1. Применить несколько фильтров.  
    2. Нажать «Сбросить фильтры» / «Очистить».  
  - ОР:
    - Фильтры снимаются.  
    - Отображается полный список товаров категории.  

- `CAT-022: Пустой результат после фильтрации`
  - Шаги:
    1. Применить такие фильтры, чтобы не осталось подходящих товаров.  
  - ОР:
    - Отображается заглушка «Нет товаров по заданным параметрам» или аналогичный текст. 
    - Есть явная возможность снять фильтры (кнопка «Сбросить»).

- `CAT-023: Применение нескольких разнотипных фильтров одновременно`
    - Шаги:
        1. Открыть категорию с товарами.
        2. Открыть панель «Фильтры».
        3. Выбрать фильтр по цене (например, «От 1000 ₽»).
        4. Выбрать фильтр по атрибуту (например, «Стекло» в разделе «Упаковка»).
        5. Выбрать фильтр «Только со скидкой».
        6. Применить фильтры.
    - ОР:
        - Отображаются только товары, соответствующие **всем** выбранным фильтрам одновременно.
        - В интерфейсе видны все активные фильтры в виде чипов или списка.
            
- `CAT-024: Последовательное добавление и удаление фильтров`
    - Шаги:
        1. Применить фильтр «Только со скидкой».
        2. Добавить фильтр по бренду (например, «Дороничи»).
        3. Удалить фильтр «Только со скидкой» через крестик на чипе.
    - ОР:
        - После удаления первого фильтра остаются товары, соответствующие оставшемуся фильтру (бренду).
        - Список товаров обновляется динамически без перезагрузки страницы.
        - Интерфейс фильтров отражает текущее состояние.
            
- `CAT-025: Фильтрация с диапазоном цен (ручной ввод)
    - Шаги:
        1. Открыть фильтры.
        2. В поле «Цена» ввести:
            - От: `500`
            - До: `2000
        3. Применить.
    - ОР:
        - Отображаются только товары с ценой от 500 до 2000 ₽ включительно.
        - Диапазон отображается в активных фильтрах («500–2000 ₽»).
        - Товары с ценой ниже 500 или выше 2000 отсутствуют.

- `CAT-026: Фильтрация по нескольким значениям внутри одного атрибута (множественный выбор)
    - Шаги:
        1. Открыть фильтры.
        2. В разделе «Упаковка» выбрать одновременно:
            - «Стекло»
            - «Пластик»
        3. Применить.
    - ОР:
        - Отображаются товары, упакованные **или** в стекло, **или** в пластик.
        - В фильтрах отмечены оба выбранных значения.

---

### 3.4. Сортировка (Sort) 

- `CAT-030: Сортировка по цене (возрастание)`
  - Шаги:
    1. Открыть список товаров.  
    2. Вызвать меню сортировки.  
    3. Выбрать «По цене: сначала дешёвые».  
  - ОР:
    - Товары упорядочены по возрастанию цены.  
    - При прокрутке порядок не меняется. 

- `CAT-031: Сортировка по цене (убывание)`
  - Шаги:
    1. Повторить шаги CAT-030, выбрать «По цене: сначала дорогие».  
  - ОР:
    - Товары упорядочены по убыванию цены.  

- `CAT-032: Сброс выбранной сортировки`
  - Шаги:
    1. Выбрать сортировку (например, по цене).  
    2. Выйти из категории и зайти в неё снова.  
  - ОР:
    - Сортировка явно сбрасывается к дефолтной.  
    - Поведение консистентно по всем категориям. 

---

### 3.5. Поиск (Search)

- `CAT-040: Поиск по полному названию товара`
  - Шаги:
    1. Открыть поиск.  
    2. Ввести запрос с точным названием товара (например, «блины с мясом»). 
  - ОР:
    - Отображаются релевантные товары, соответствующие запросу. 

- `CAT-041: Поиск по части названия`
  - Шаги:
    1. Ввести только часть названия (например, «блины»).  
  - ОР:
    - Отображается список товаров, в названии которых есть введённая подстрока. 

- `CAT-042: Динамические подсказки при вводе`
  - Шаги:
    1. Начать вводить название товара по буквам.  
  - ОР:
    - Под полем ввода появляются подсказки (товары/категории), обновляющиеся по мере ввода. 
    - Нажатие на подсказку открывает список/товар, соответствующий подсказке. 

- `CAT-043: Переход к товару из результата поиска`
  - Шаги:
    1. Выполнить поиск с валидным запросом.  
    2. Нажать на товар в результатах поиска.  
  - ОР:
    - Открывается карточка товара, соответствующая выбранной позиции.

---

### 3.6. Пустой поиск / нет результатов

- `CAT-050: Поиск с отсутствием результатов`
  - Шаги:
    1. Ввести в поиск заведомо «левый» запрос (например, «абракадабра»). 
  - ОР:
    - Отображается заглушка «Ничего не найдено». 

- `CAT-051: Повторный поиск после пустого результата`
  - Шаги:
    1. Выполнить поиск с «абракадабра».  
    2. Не уходя с экрана, ввести новый валидный запрос.  
  - ОР:
    - Заглушка «Ничего не найдено» исчезает.  
    - Появляется список релевантных товаров по новому запросу. 

---

### 3.7. Пустые категории / «нет товаров»

- `CAT-060: Подкатегория без товаров`
  - Шаги:
    1. Открыть подкатегорию, для которой в PIM нет активных товаров (тестовые данные).  
  - ОР:
    - Отображается понятная заглушка «В этой категории пока нет товаров» или аналог. 
    - Нет белого пустого экрана.  

- `CAT-061: Категория без подкатегорий и товаров`
  - Шаги:
    1. Открыть категорию, у которой нет ни подкатегорий, ни товаров (ошибка/особый случай PIM).  
  - ОР:
    - Показывается заглушка с текстом и, возможно, ссылкой/кнопкой «Вернуться в каталог». 

---

### 3.8. Производительность и кэширование

- `CAT-070: Время загрузки каталога`
  - Шаги:
    1. Запустить приложение.  
    2. Открыть «Каталог» (при нормальном интернете).  
  - ОР:
    - Каталог отображается не более чем за 2 секунды на целевых устройствах.

- ==`CAT-071: Отображение кэшированного каталога без интернета`==
  - Шаги:
    1. Открыть каталог при наличии сети (загрузить актуальные категории/товары).  
    2. Закрыть приложение.  
    3. Отключить интернет.  
    4. Снова открыть приложение и перейти в «Каталог».  
  - ОР:
    - Отображается закэшированный список категорий/товаров.
    - Явно или неявно видно, что данные могут быть не обновлены. 

---

### 3.9. Ошибки сети / PIM

- `CAT-080: Нет интернета при первой загрузке каталога`
  - Шаги:
    1. Установить приложение, не открывая каталог.  
    2. Отключить интернет.  
    3. Открыть «Каталог» впервые.  
  - ОР:
    - Отображается сообщение о проблеме с сетью («Нет интернета»). 
    - Пользователю доступна кнопка «Повторить» / «Обновить». 

- `CAT-081: Ошибка PIM / сервера при загрузке каталога`
  - Шаги:
    1. Сымитировать ошибку 5xx или невалидный ответ PIM при запросе категорий/товаров. 
    2. Открыть «Каталог».  
  - ОР:
    - Появляется заглушка «Не удалось загрузить каталог» или аналог. 
    - Можно уйти в другие разделы приложения, интерфейс не «ломается».

- `CAT-082: Ошибка при выполнении поиска`
  - Шаги:
    1. Отключить сеть или сымитировать ошибку сервиса поиска.  
    2. Ввести любой поисковый запрос.  
  - ОР:
    - Отображается сообщение об ошибке сети/сервера, а не «Ничего не найдено». 
    - Пользователь может повторить запрос после восстановления сети.
