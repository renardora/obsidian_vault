Включает:  
- Sign In  
- Sign Up  
- Confirmation code (SMS / OTP)  
- Logout / Disconnect  

---
## 1. Краткий обзор модуля

Назначение:  
Обеспечить пользователю регистрацию или вход по номеру телефона, подтверждение SMS-кодом, создание профиля для участия в программе лояльности, а также корректное завершение сессии (logout).

---
## 2. Группы проверок

- Базовые позитивные сценарии авторизации  
- Регистрация и обязательные поля  
- SMS / OTP: корректные и ошибочные состояния  
- Валидация форм  
- Состояния авторизован / неавторизован  
- Выход из аккаунта  
- Ошибки сервера / сети  

---
## 3. Тест-кейсы

### 3.1. Состояние без авторизации

- AUTH-001: Призыв к авторизации на главном экране
  - Шаги:
    1. Запустить приложение без авторизации.  
    2. Перейти на главный экран.
  - ОР:
    - Показывается сообщение: «Войдите в аккаунт, чтобы стать участником программы лояльности…»  
    - Отображается кнопка «Вход/Регистрация».

### 3.2. Регистрация

- AUTH-010: Регистрация нового пользователя (валидный сценарий)
  - Шаги:
    1. Нажать «Регистрация».  
    2. Ввести корректный номер телефона.  
    3. Получить SMS-код.  
    4. Ввести корректный SMS-код.  
    5. Заполнить email, дату рождения, пол (валидные данные).  
    6. Нажать «Сохранить».
  - ОР:
    - Регистрация успешна.  
    - Пользователь перенаправлен в профиль.  
    - Бонусный баланс = 0.

### 3.3. Авторизация (вход)

- AUTH-020: Вход по номеру и SMS-коду (валидный)
  - Шаги:
    1. Нажать «Вход».  
    2. Ввести номер зарегистрированного пользователя.  
    3. Ввести корректный SMS-код.
  - ОР:
    - Успешный вход.  
    - Отображается баланс бонусов.

- AUTH-021: Повторный вход без запроса SMS (токен валиден)
  - Шаги:
    1. Войти.  
    2. Полностью перезапустить приложение.
  - ОР:
    - Пользователь остаётся авторизованным.  

### 3.4. SMS / OTP

- AUTH-030: Ошибка при вводе неверного SMS-кода
  - Шаги:
    1. Получить SMS.  
    2. Ввести неверный код.
  - ОР:
    - Показано сообщение: «Код введен неверно».  
    - Возможность повторить ввод.

- AUTH-031: Повторная отправка SMS-кода через 60 секунд
  - Шаги:
    1. Ввести номер телефона.  
    2. Получить SMS-код.  
    3. Дождаться 60 секунд.  
    4. Нажать «Отправить код повторно».
  - ОР:
    - Кнопка становится активной после таймера.  
    - Новое SMS отправлено.
    - Появляется модальное окно, оповещающее о том, что код отправлен.

- AUTH-032: Повторная отправка SMS до истечения таймера
  - Шаги:
    1. Получить SMS-код.  
    2. Попытаться нажать «Отправить код повторно» до окончания 60 секунд.
  - ОР:
    - Кнопка недоступна.  
    - Отображается таймер.

- AUTH-062: Время жизни кода подтверждения
  - Шаги:
    1. Получить SMS-код.  
    2. Подождать 120 секунд.
    3. Попробовать использовать код, полученный в шаге 1.
  - ОР:
    - Показано сообщение: «Код введен неверно».  
    - Возможность повторить ввод.

### 3.5. Валидации

- AUTH-040: Неверный формат номера телефона
  - Шаги:
    1. Ввести явно некорректный номер («123», «+7abc…»).  
    2. Нажать «Получить код».
  - ОР:
    - Ошибка формата телефона.  
    - Запрос SMS не отправляется.

- AUTH-041: Валидация email при регистрации
  - Шаги:
    1. Ввести невалидный email.  
    2. Нажать «Сохранить».
  - ОР:
    - Предупреждение о неверном формате.  
    - Сохранение не происходит.

- AUTH-063: Валидация даты рождения при регистрации
  - Шаги:
    1. Ввести невалидную дату рождения .  
    2. Нажать «Сохранить».
  - ОР:
    - Предупреждение о неверном формате.  
    - Сохранение не происходит.

### 3.6. Logout / Disconnect

- AUTH-050: Выход из аккаунта
  - Шаги:
    1. Открыть профиль.  
    2. Нажать «Выйти».
  - ОР:
    - Сессия сброшена.  
    - Пользователь переведён в неавторизованное состояние.

- AUTH-051: Приложение после выхода (перезапуск)
  - Шаги:
    1. Выйти.  
    2. Перезапустить приложение.
  - ОР:
    - Пользователь остаётся неавторизованным.  
    - Показывается главный экран с призывом к авторизации.

### 3.7. Ошибки сервера / сети

- AUTH-060: Нет интернета при отправке SMS
  - Шаги:
    1. Отключить интернет.  
    2. Нажать «Получить код».
  - ОР:
    - Отображается ошибка сети.  
    - SMS не отправляется.

- AUTH-061: Ошибка сервера при подтверждении кода
  - Шаги:
    1. Ввести корректный код.  
    2. Сымитировать ответ сервера с ошибкой.
  - ОР:
    - Показана ошибка.  
    - Вход не выполнен.
